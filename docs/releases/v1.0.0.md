NeuroLoom（织络）的第一个正式版本：把 PyTorch 模型变成可编辑的节点图，在图和代码之间双向转换。

## 主要功能

- **搭建**：
  - 84 个层与算子节点，7 个可展开的复合模块（残差块、多头注意力、Transformer 块……）。
  - 参数可以写成引用模块超参数的表达式。
  - 选中节点按 Ctrl+G 打包为模块，双击进入；模块可以复用，也可以串联重复。
- **形状与分析**：
  - 边上实时显示张量形状，支持 batch 等符号维度。
  - 问题面板列出形状不匹配等错误，点击定位到节点。
  - 参数量、FLOPs、激活与显存估算。
- **数据流**：边上的流动动画；前向传播回放，可以进入模块内部。
- **导出**：
  - PyTorch 代码，每个模块一个类。
  - 导出选项：形状注释、类型标注、嵌套调用、自测片段等，也可以拆成每个类一个文件的包。
  - 画布导出为 SVG / PNG / PDF。
- **导入**：
  - 静态解析（不执行代码），保留子模块、变量名和超参数表达式；读不懂的语句保留为代码块。
  - “运行后导入”执行一次代码，把循环构造的层按实际结构展开。
  - 常见开源仓库的模型文件中，入口类直接继承 `nn.Module` 的 41 个文件里有 37 个可以导入，生成的代码与原模型等价。
- **模板**：12 个，从 MLP 到 ResNet-50、U-Net、ViT、GPT-2，都附原始论文链接。
- **文件**：
  - `.loom` 项目文件按键排序保存，便于用 git 管理；有自动保存与崩溃恢复。
  - 以后的版本保存的文件，在这个版本里以只读方式打开，并提示升级。
- **界面**：中文 / English，深浅色主题。

## 安装

| 平台 | 文件 |
| --- | --- |
| Windows | `NeuroLoom-1.0.0-win-x64-setup.exe` |
| macOS（Apple 芯片） | `NeuroLoom-1.0.0-mac-arm64.dmg` |
| macOS（Intel） | `NeuroLoom-1.0.0-mac-x64.dmg` |
| Linux | `NeuroLoom-1.0.0-linux-x64.deb`（推荐）或 `NeuroLoom-1.0.0-linux-x64.AppImage` |

安装包没有代码签名，第一次打开时系统会拦一下：
- **Windows**：出现“Windows 已保护你的电脑”时，点“更多信息”，再点“仍要运行”。
- **macOS**：
  - 提示无法验证开发者时，打开“系统设置 → 隐私与安全性”，点“仍要打开”。
  - 提示“已损坏，无法打开”时，在终端运行 `xattr -dr com.apple.quarantine /Applications/NeuroLoom.app` 后再打开。
- **Linux**：从 Ubuntu 24.04 起，AppImage 要加 `--no-sandbox` 才能启动（会关闭渲染进程的沙箱），所以建议用 `.deb`。

编辑、形状推断和导出代码不需要 Python。导入代码、运行后导入和“运行一次补全形状”需要本机的 Python 3.10+ 和 PyTorch：
- 在“文件 → Python 环境”里可以选择已有的环境；
- 也可以用本机的 Python 一键创建一个带 CPU 版 PyTorch 的环境。

## 已知限制

- 只有模型结构：不包含损失函数、优化器和训练。
- 入口类继承框架基类的文件不能导入，例如 transformers 的 `PreTrainedModel`、diffusers 的 `ModelMixin`。
- `forward()` 中途 `return` 的类，整类保留为源码。
- 没有自动更新。
